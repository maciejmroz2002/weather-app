# Weather App

A modern, interactive weather application that provides real-time weather information with additional features like daily historical facts and themed visuals.

## Features

- **City Search**: Search weather information for any city worldwide
- **Real-Time Weather Display**: Shows current temperature, location, time, and date
- **Dark Mode**: Toggle between light and dark themes for comfortable viewing
- **Daily Gif**: Display a weather-themed GIF for the current day
- **Historical Facts**: Get interesting facts about what happened on today's date in history
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Dynamic Backgrounds**: Weather-appropriate background images
- **Weather Icons**: Visual indicators for different weather conditions

## Technologies Used

- **HTML5**: Application structure and semantic markup
- **CSS3**: Responsive styling with CSS variables for theming
- **JavaScript**: Core functionality and API integration
- **Font Awesome**: Icon library for UI elements

## Usage

1. Open `index.html` in your web browser
2. Use the search bar to find a city
3. View the current weather information
4. Click buttons to:
   - **Gif for today**: See a weather-themed GIF
   - **Today in history**: Learn historical facts for today's date
   - **Dark Mode**: Toggle the color scheme
5. Use the menu icon to access navigation options
